# O pequeno universo do nosso amor

Textos atualizados para Amor, meu amor, meu bem e minha linda.

Envie todos os arquivos extraídos para a raiz do mesmo repositório GitHub. Confirme em Commit changes. O workflow publicar.yml organiza os arquivos e publica no GitHub Pages.

Não é necessário renomear o repositório. As chaves internas do armazenamento foram preservadas para manter o diário e a compatibilidade com backups.
