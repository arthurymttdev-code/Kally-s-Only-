# O pequeno universo do nosso amor

Música principal: Anjos, de Venere Vai Venus. Player oficial do YouTube visível na seção de música, com controles reais. Toque em Play para começar. Não há download de áudio nem promessa de reprodução automática. Disponibilidade depende do YouTube e da conexão do visitante.

Envie todos os arquivos extraídos deste ZIP à raiz do mesmo repositório GitHub e confirme em Commit changes. O workflow publicar.yml organiza os arquivos e publica automaticamente. Aguarde build e deploy concluírem com sucesso.

O pacote mantém Amor e os apelidos carinhosos. As memórias continuam locais no navegador, com exportação e importação de backup.

Música oficial: https://www.youtube.com/watch?v=mJjHVOv2bWI
